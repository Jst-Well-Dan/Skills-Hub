# Skills-Hub Project Guidance

## Repository Layout

- `libraries/` contains source snapshots of upstream projects. Do not edit these copies unless a task explicitly requires it. Internal maintenance skills (e.g. `skillhub-ingest`) remain here but are excluded from the public catalog.
- `extracted-skills/` contains standardized, ready-to-use installable outputs generated by `scripts/extract_skills.py`. Do not hand-edit files in this directory.
- `registry/` is the single source of truth for the catalog:
  - `registry/projects.yaml`: All indexed repositories and their individual skills metadata.
  - `registry/categories.yaml`: Category identifiers, display labels, and sorting definitions.
  - `registry/tags.yaml`: Tag definitions and classification keywords.
- `reviews/` contains markdown articles for in-depth reviews, combinations, and best practice guides.
- `README.md`, `docs/`, and `site/index.html` are compiled artifacts generated from the registry and review sources. Regenerate them instead of making isolated manual edits.

## When Catalog Data Changes

After modifying upstream libraries, project metadata, or category/tag configurations, run the relevant compilation pipeline:

```powershell
# 1. Extract installable skills from libraries/
python scripts/extract_skills.py [--project <project-id>]

# 2. Update markdown documentation and README.md index
python scripts/generate_docs.py

# 3. Compile the static web application and skill content index
python scripts/generate_site.py
```

## Local Admin Workbench & Deployment

Skills-Hub provides a lightweight local management backend and web interface:

- **Start Admin**: Run `start-admin.bat` or `python scripts/admin_server.py --port 5173`.
- **Admin UI**: Open `http://127.0.0.1:5174/index.html?admin=1`.
- **Capabilities**:
  - Visual category management (create, rename, reorder, delete categories).
  - Multi-select projects or skills and batch move them across categories.
  - One-click deployment: Select skills/projects and deploy directly to any local project path (e.g., `.claude/skills/`, `.agents/skills/`, `.codex/skills/`).
  - Trigger static site and documentation rebuilds directly from the web interface.

## Deduplication and Integrity Rules

- **Deduplication**: Identical `SKILL.md` files within a project (e.g., root vs. nested plugin paths) are deduplicated by SHA-256 hash, keeping the canonical deeper path.
- **Validation**: Validate YAML/JSON formatted registry files and ensure no temporary `libraries/.*.tmp/` directories remain.
- **Preserve Changes**: Preserve unrelated worktree changes, including intake repositories that may be in progress.
