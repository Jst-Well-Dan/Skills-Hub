【模板：粗野主义网页原型】
【意图】瑞士工业印刷风格，不柔和、不友好，具有强烈的权威感。
【布局】

- 新闻纸画布 + 细线网格分隔线
- 整块黑色无衬线标题、延伸出视口的巨型数字
- 危险红强调色 + ASCII 装饰（┌─┘ 等）
- 各部分使用极简数字编号
