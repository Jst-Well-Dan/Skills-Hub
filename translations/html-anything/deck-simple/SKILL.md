【模板：简约幻灯片】
【意图】干净通用的横向滑动幻灯片（提案 / 概览 / 学习）。
【布局】

- 封面 + N 个内容页 + 收尾（N 由【用户内容】长度决定，完整覆盖每个要点；短内容从 6-10 页起步，长内容应更多）
- 每页一个核心信息 + 1 张图 / 1 个图表
- 顶部进度条

【设计细节】

- 键盘 ← / → 切换 + URL 片段同步
