【模板：等候名单页 / 等候名单】
【意图】为新产品 / 早鸟内测制作一张极简等候页。
【布局】
- 居中布局：品牌徽标 + 一行宣传语 + 大字号主视觉文案（说清楚产品用途）
- 邮箱收集输入框 + 提交按钮（合并成一个胶囊形组件）
- 下方 3 个小卖点（图标 + 一行文字）
- 底部创始人寄语 + 社交链接
【设计细节】
- 装饰：SVG 渐变网格 / 噪点纹理 / 一条星轨
- 成功提交后展示一个微动效（✓ + 文案变化）
