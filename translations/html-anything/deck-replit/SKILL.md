【模板：Replit Slides 风格演示文稿】
【意图】采用 Replit Slides 风格的单文件横向滑动演示文稿，选择 1 套主题且不混用。
【布局】

- 选择一个主题：helix / holm / vance / bevel / world-dark / world-mint / atlas / bluehouse
- 封面 + 议程 + N 个内容页 + 收尾（N 由【用户内容】长度决定，完整覆盖每个要点；短内容从 6-10 页起步，长内容应更多）

【设计细节】

- 每套主题均有完整的调色板 + 字体 + 强调色，不要混用
