【模板: SaaS 落地页】
【意图】完整的 SaaS 产品落地页, 把用户内容映射到标准区块。
【布局】
- 顶部导航 (logo + 导航 + 登录 + 主要行动号召)
- 首屏区 (大标题 + 副标题 + 双行动号召 + 可视化占位)
- Logo 墙 (社会认同)
- 功能特性 (3-6 个特性卡片, icon + 标题 + 描述)
- 工作原理 (3 步流程, 数字 + 标题 + 描述)
- 定价 (2-3 档, 推荐档高亮)
- 常见问题 (`details`/`summary` 手风琴)
- 页脚
【设计细节】
- 现代 SaaS 风: 大字号, 柔和渐变, 玻璃拟态卡片, 滚动入场动画
- 至少处理 `md:` 断点, 移动端单栏
