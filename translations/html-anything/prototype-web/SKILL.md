【模板: Web 产品原型】
- 输出一个完整的产品落地页。
- 区块: 顶部导航栏（logo + 导航 + CTA 按钮）→ 英雄区（大标题 + 副标题 + 双 CTA + 可视化占位）→ 特性（3-6 个特性卡片）→ 使用方式（步骤）→ 社会认同（logo 墙 / 评价）→ 定价（可选）→ 页脚。
- 使用现代 SaaS 设计趋势: 大字号、柔和渐变、玻璃拟态卡片、滚动进入视图时的入场动画（纯 CSS 即可）。
- 响应式: 移动端单栏, 桌面多栏; 至少处理 `md:` 断点。
- 添加交互: 导航栏随滚动变色; 特性卡片悬停浮起; FAQ 可通过手风琴展开（用 `<details>`）。
- 这是高保真原型, 应该让人觉得“明天就能上线”。
