【模板：Kami 羊皮纸文档】
【意图】严肃排版文档：单页文档 / 长报告 / 信函 / 简历 / 财报 / 更新日志 / 作品集。灵感源自 tw93/kami。强调“写得像被排过版的纸”，不是仪表盘，不是网页。

【硬性视觉签名 — 不许改】
- **画布**：暖羊皮纸 `#f5f4ed`（永远不用纯白 `#fff`）。次级背景 `#efeee5`。
- **墨色**：主文字 `#1f1d18`（近黑暖灰，不用纯黑 `#000`）。次文字 `#6b665b`。
- **唯一色彩**：墨蓝 `#1B365D` —— 所有强调元素（链接、标签描边、重点数字、引用左侧线条）只能用这一个颜色，严禁多色。
- **字体**：一种语言一种衬线字体，全文不混用：
  - 英文：`Charter`（后备字体：`Source Serif Pro`、`Iowan Old Style`）
  - 中文：`TsangerJinKai02 W04`（后备字体：`Noto Serif SC`）
  - 日文：`YuMincho`（后备字体：`Noto Serif JP`）
  - 正文 400，标题 500（不要 700/800/900）。
- **行高**：标题 1.1–1.3，紧凑正文 1.4–1.45，阅读型正文 1.5–1.55。
- **绝不**：投影 / 模糊 / 圆角 ≥ 8px / 渐变 / 霓虹色 / rgba（使用纯色十六进制值）。
- **细节**：标签使用纯色十六进制背景方块（因为 WeasyPrint 无法良好渲染 rgba）；单线几何图标；边缘使用 1px 极细 `#d4d1c5` 分隔线，长度受控且不延伸到边缘。

【可选文档类型 — 按用户内容判断】
- **单页文档** — 顶部标识（Charter 斜体）+ 标题 + 导语 + 3 列要点 + 底部元数据。
- **长文档** — 封面页（大标题 + 副标题 + 作者 + 日期）→ 目录（引导标题 + 页码）→ 章节（顶角页码 + 章节分隔线 + 正文）→ 注释脚注 + 文末出版说明。
- **信函** — 抬头地址 + 日期 + 收件人 + 正文（左对齐，段间空 1.5em）+ 署名 + 签名占位线。
- **作品集** — 项目主视觉（大标题 + 副标题）+ 1 张全幅图（用 CSS 块绘制占位）+ 项目描述 + 角色 / 时间 / 技术栈元数据行。
- **简历** — 顶部姓名（大字）+ 一行简介 + 联系方式行 + 主要章节：工作经历（公司 / 时间 / 职位 / 项目符号列表）+ 技能 + 教育经历。
- **幻灯片** — 主题演讲风格，页数由【用户内容】决定（短内容 6 页起步，长内容应更多），每页满铺羊皮纸，大标题 + 导语 + 角标页码，简洁到只有“被印出来”的感觉。
- **股票研究报告** — 公司名 + 股票代码 + Q × 年份 + 关键指标行（营收 / 利润率 / 同比）+ 正文分析 + 图表（SVG 单色折线）。
- **更新日志** — 版本号（Charter 斜体大字）+ 日期 + 改动列表（新增 / 变更 / 修复），以单条分隔线区隔。

【设计准则】
- “排版成章的页面，而非仪表盘。”不要堆砌关键绩效指标卡片，不要堆砌表情符号图标，不要使用主视觉渐变。
- “只用轮廓或轻柔暗示，不用生硬投影。”阴影只能是 `0 0 0 1px #d4d1c5` 这种极细描边。
- 文字层级依靠**衬线对比 + 字号 + 留白**，不依靠颜色。
- 使用单文件 HTML 和 Tailwind CDN；全文中英混排时加入盘古之白；不要外链图片，占位使用纸张色调色块 + 1px 墨色描边。
