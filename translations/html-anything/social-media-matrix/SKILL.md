【模板：社媒矩阵追踪（Social Matrix Tracker）】
【意图】电影感、数据密集的多平台社媒看板。
【布局】
- 主视觉页眉（统一品牌 + 时间窗 + 主题切换）
- 多平台 KPI 矩阵（横向 platform × 纵向 metric）
- 交互式图表（悬浮提示 + 区间对比）
- 洞察抽屉（右侧抽屉，文字洞察）
- 热门帖子网格
【设计细节】
- 深色 / 浅色切换；数据用 seed 兜底
