【模板：杂志风海报 / Magazine Poster】
【意图】报纸编辑风格的长图海报，读起来像一篇报纸全版。
【布局】

- 日期栏顶栏（刊物 / 日期 / 期号）
- 超大衬线体标题（包含删除线词语 + 斜体强调）
- 双栏正文
- 6 个编号章节，每个包含小标题 + 1-2 段正文 + 引文
- 底部署名 + 小型装饰图案

【设计细节】

- 纸张质感：暖灰奶油色背景 + 细密圆点图案，黑色文字
- 字体：Playfair Display + IBM Plex Serif + JetBrains Mono
