【模板：竞品拆解】
【意图】这不是文章、不是 PRD、不是推介演示文稿。目标是把多个竞品的杂乱资料转成一份可决策的产品战略报告，帮助团队回答：“我们和它们到底差在哪里，下一步该怎么打？”

【适合输入】
- 竞品官网 / 定价页 / 更新日志 / 用户评论 / 销售反馈 / 内部调研笔记
- 2-6 个竞品最合适；如果用户只给一个竞品，输出单竞品深度分析
- 可以包含表格、项目符号、链接摘录、访谈记录、截图说明

【必须输出的结构】
1. 页眉：市场 / 产品类别 / 报告日期 / 一句话结论。
2. 执行摘要：3 条最重要判断，每条必须包含“这意味着什么”。
3. 定位图：用 2×2 象限或坐标图表现竞品定位。坐标轴必须来自用户内容，不要套用模板词。
4. 竞品卡片：每个竞品一张卡片，包含目标用户、核心承诺、定价信号、主要优势、明显弱点。
5. 功能矩阵：行是关键能力，列是竞品 +“我们 / 机会”；用 ✓ / △ / — 表达覆盖度，并用短注释说明。
6. 定价 / 套餐分析：价格层级、免费试用、限制项、企业销售动作。
7. 用户体验 / 信息传达要点：从用户材料中抽取 4-6 条可观察细节，不要泛泛而谈。
8. 机会窗口：3 个机会窗口，每个包含为何是现在、目标细分市场、第一步行动、风险。
9. 建议行动：近期 30 天 / 90 天 / 180 天行动建议。

【设计要求】
- 战略咨询 + 产品战情室风格：信息密度高、扫描快、图表清楚。
- 使用克制的配色方案：墨色 / 纸色 / 柔和蓝 / 信号琥珀色，或类似的专业色彩。
- 功能矩阵必须横向可读；小屏可变成堆叠卡片。
- 不要做成营销落地页，不要做成普通文章。

【可选风格模板 — 参考 assets/】
根据用户内容选择最贴合的一种，不要三种混用：
- `assets/war-room-grid.html`：默认风格。浅色战情室 / 咨询报告，适合产品团队、PM、普通商业读者。
- `assets/radar-map.html`：深色雷达图 / 市场情报控制台，适合安全、AI、开发者工具、平台型竞品。
- `assets/analyst-dossier.html`：纸质分析档案 / 投资研究档案，适合投研、行业分析、正式战略备忘。

如果用户没有指定风格，优先使用 `war-room-grid`；如果输入强调市场格局、技术雷达、攻防态势，使用 `radar-map`；如果输入像研究笔记、投资备忘或行业报告，使用 `analyst-dossier`。

【内容真实性】
- 只使用用户提供的竞品、价格、功能、评论。缺失信息用“来源中未找到”或“未知”标注。
- 不要虚构市场份额、ARR、客户名、定价数字。
- 如果用户资料明显不足，仍然输出报告，但在“证据缺口”中列出缺口。
