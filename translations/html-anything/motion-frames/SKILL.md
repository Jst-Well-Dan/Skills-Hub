【模板：动效帧 / 循环英雄区】
【意图】一帧带循环动效的英雄区，可作为视频片头或落地页大图。
【布局】
- 旋转文字环（SVG + transform）
- 动态地球仪 / 抽象几何
- 跳动计时器（等宽字体，JS 可有可无）
- 浮动视差标签
【设计细节】
- 纯 CSS 动效，流畅可循环
- 电影感调色 + 1 个霓虹强调色
