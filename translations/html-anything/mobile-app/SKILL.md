【模板：iPhone 单屏应用】
【意图】一个屏幕的移动应用设计，放在像素级 iPhone 15 Pro 边框里。
【布局】
- 状态栏（时间 + 电池 + 信号）
- 应用标题栏（标题 / 头像 / 搜索）
- 主要内容（一种清晰的原型：信息流 / 列表 / 详情 / 表单）
- 底部标签栏（4-5 个标签）
【设计细节】
- 真实的灵动岛；为安全区域留白
