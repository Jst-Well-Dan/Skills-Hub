【模板：博客长文 / Blog Post】
【意图】≥ 600 字的真正长文章，排版以字体设计为主，70% 文字、20% 图片、10% 界面装饰。
【布局】
- 报头（刊物名称 + 日期）
- 主视觉（大标题 + 副标题 + 作者署名 + 阅读时间）
- 正文（单栏 65ch，包含插图、醒目引文、行内引用）
- 作者简介卡片
- 相关文章（3 张卡片）
【设计细节】
- 醒目引文使用大号 serif 斜体 + 左侧色条
- 插图自带说明文字（斜体、较小字号）
- 代码块：圆角 + 深色 + 语言标签
