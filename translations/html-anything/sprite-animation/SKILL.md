【模板：像素 / 8-bit 动画解说】
【意图】教育型动画的单帧海报，使用纯 CSS keyframes 循环，不使用 JS。
【布局】

- 全出血米色舞台
- 醒目的展示年份 / 大字数字
- 中心放置一个像素艺术吉祥物（使用 SVG 或纯 CSS 绘制）
- 动态中文 / 日文展示字体
- 底部时间轴条持续滚动

【设计细节】

- 动画使用 @keyframes，不依赖 JS
- 复古调色板：红 / 米 / 墨绿
