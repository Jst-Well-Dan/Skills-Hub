---
name: handoff
description: 将当前对话精简为一份交接文档，供另一位智能体接手。
argument-hint: "下一会话将用于什么工作？"
disable-model-invocation: true
---

编写一份总结当前对话的交接文档，以便新的智能体可以继续工作。将其保存到用户操作系统的临时目录中，而不是当前工作区。

在文档中包含一个“建议技能”章节，推荐智能体应调用的技能。

不要重复已记录在其他产物（PRD、计划、ADR、议题、提交、差异）中的内容。请通过路径或 URL 引用它们。

隐去任何敏感信息，例如 API 密钥、密码或个人身份信息。

如果用户传入了参数，请将其视为下一会话重点的描述，并据此调整文档。
