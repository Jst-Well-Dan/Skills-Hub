name: research
description: 基于高度可信的一手来源调查问题，并将调查结果保存为仓库中的 Markdown 文件。当用户希望研究某个主题、收集文档或 API 事实，或将资料查阅工作委派给后台智能体时使用。
---

启动一个**后台智能体**来执行研究，以便在它查阅资料时你可以继续工作。

它的任务：

1. 基于**一手来源**调查问题——官方文档、源代码、规范、第一方 API——而不是介绍这些内容的二手文章。将每一项主张追溯到对其负责的原始来源。
2. 将调查结果写入单个 Markdown 文件，并为每一项主张标注来源。
3. 将其保存到仓库中现有的同类笔记存放位置；遵循现有约定，如果没有此类约定，则将其放在合理的位置并说明具体位置。
