# AI 演示文稿工作流

创建专业演示文稿：内容 → 设计 → 构建 → 组装 → 润色。

## 步骤 0：选择工作流设置

**每次开始演示文稿任务时，都要让用户做出以下两项选择：**

### 0-A. 协作模式

| 模式 | 描述 | 检查点 |
|------|-------------|-------------|
| **全自动** | 最少交互。仅确认主题，然后交付最终 PPTX。 | 1 个检查点 |
| **引导式**（推荐） | 确认大纲、选择设计，并在组装前预览。 | 3 个检查点 |
| **协作式** | 审阅每一页幻灯片、批准每一幅插画，完全掌控。 | 逐页 |

如果用户未指定，默认使用**引导式**模式。

### 0-B. 组装方法

| 方法 | 工作方式 | 最适合 |
|--------|-------------|----------|
| **可编辑 HTML**（路径 A） | HTML 幻灯片 + 选择性 AI 插画 → html2pptx → 可编辑 PPTX | 后续需要编辑文字、精确布局、企业演示文稿 |
| **全 AI 视觉**（路径 B） | 每页幻灯片都是完整的 AI 生成图片 → create_slides.py → 图片型 PPTX | 追求最大视觉冲击力、艺术化演示文稿、快速草稿 |

**权衡：**

| | 路径 A：可编辑 HTML | 路径 B：全 AI 视觉 |
|---|---|---|
| 文字 | 可在 PPT 中编辑 | 已嵌入图片（不可编辑） |
| 视觉质量 | 配合插画时效果良好 | 出色——设计风格统一 |
| 布局控制 | 像素级精确 | 由 AI 解读 |
| 文件大小 | 较小（约 5-25MB） | 较大（约 30-80MB） |
| 中文文字 | 完美（字体渲染） | 通常良好（AI 偶尔可能渲染错误） |
| 速度 | 更快（创建 HTML） | 更慢（每页都要生成图片） |

如果用户未指定，默认使用**路径 A**（可编辑 HTML）。

## 步骤 1：内容结构化

将原始材料整理成逐页幻灯片大纲。

**每页幻灯片需定义：**
- **标题**——完整的论断句（不是主题词）
- **要点**——最多 3-4 个
- **视觉类型**——插画 / 图表 / 图示 / 图标 / 引语
- **路径 A：**是否需要插画？——是/否。如果是，用一句话描述。
- **路径 B：**视觉场景描述——用一段话描述完整的幻灯片视觉效果（布局 + 图像 + 氛围）。

**论断—证据原则：**

| 差标题 | 好标题 |
|-----------|-----------|
| 第三季度销售额 | Q3销售增长23%，新用户是主要驱动力 |
| 研究方法 | 我们通过双盲实验验证了这个结论 |

**语言规则：slide内容一律用中文，仅保留必要的英文术语（人名、品牌名、技术专有名词）。** Section label（如 INSIGHT、TAKEAWAY）可用英文作为设计元素。

### ✅ 检查点 1（引导式 + 协作式）

以表格形式展示大纲：

**路径 A：**
```
| # | 标题（论断） | 要点 | 视觉类型 | 插画？ |
|---|-------------------|------------|-------------|---------------|
| 1 | 封面：... | — | 装饰性 | 是：... |
| 2 | ... | 1. ... 2. ... | 图表 | 否 |
| 3 | ... | 1. ... 2. ... | 插画 | 是：... |
```

**路径 B：**
```
| # | 标题（论断） | 要点 | 视觉场景描述 |
|---|-------------------|------------|--------------------------|
| 1 | 封面：... | — | 深色渐变背景，大标题居中，抽象网络节点 |
| 2 | ... | 1. ... 2. ... | 分栏布局：左侧文字、右侧条形图、简洁白色背景 |
| 3 | ... | 1. ... 2. ... | 全幅插画：站在十字路口的人，周围漂浮着时钟 |
```

**询问用户：**
- 批准 / 调整幻灯片页数
- 路径 A：批准 / 调整哪些幻灯片使用插画
- 路径 B：批准 / 调整视觉场景描述
- 是否有需要添加或删除的内容

**第一梯队（强烈推荐，效果极好）：**

**1. 温暖连环漫画** — Snoopy温暖漫画风
- 设计哲学：Peanuts漫画的温暖与哲理感——简单的角色说着深刻的话，日常场景中蕴含人生智慧
- 视觉世界：圆头小孩、小狗、小鸟组成一个温暖的小世界。背景极简（草地、天空、狗屋、树）。色调像泛黄的报纸漫画
- 参考："像 Peanuts 连环漫画——温暖、富有哲理、迷人"
- **风格指南：** `references/proven-styles-snoopy.md`
- **⚠️ 关键经验：** 不要在prompt中过度约束视觉细节（颜色比例、构图位置、角色姿势），否则会严重降低多样性。只描述情绪和内容，让AI自由发挥

**2. 教育漫画** — 学習漫画风
- 设计哲学：日本教育漫画（学習漫画）——由一个角色通过反应和戏剧性表现来引导你理解概念
- 色彩：明亮温暖的配色，白色背景搭配局部彩色分镜，使用网点灰强调重点区域
- 比例：60% 插画 / 30% 文字（气泡内）/ 10% 特效
- 字体排印：标题采用醒目有冲击力的漫画风格，正文置于对话/思考气泡中，拟声词作为装饰元素。字号对比 3:1
- 构图：动态漫画分镜布局（每页 3-5 格），通过角色反应突出重点，用速度线营造动感，采用戏剧化视角
- 视觉语言：表情丰富的动漫风格角色、反应表情（惊讶、困惑、顿悟！）、漫画特效（汗滴、闪光、速度线）、粗细不一的分镜边框
- 参考："像《漫画统计学入门》中的一页——角色带你逐步理解概念，并以惊讶和喜悦作出反应"

**3. 清晰线条漫画** — 清线漫画风
- 设计哲学：Hergé 的 Tintin 传统——通过视觉克制实现最大程度的信息清晰度
- 色彩：白色/奶油色（#FFFDF7）背景、黑色（#000000）轮廓线、平涂高饱和色彩（3-5 种纯色，无渐变）
- 比例：70% 简洁背景 / 20% 插画 / 10% 文字
- 字体排印：标题带有手写字感，正文使用简洁无衬线字体。关键引语使用对话气泡。标题:正文 = 2.5:1
- 构图：基于分镜的布局（每页 2-4 格），从左到右顺序阅读，分镜之间留有清晰间隔
- 视觉语言：统一粗细的轮廓线、无阴影或排线的平涂色彩、无渐变、细节精准但无任何视觉噪声
- 参考："像解释某个概念的 Tintin 漫画页——每个分镜都推动理解，没有任何纯装饰元素"

**4. 新波普杂志** — 新波普杂志风
- 设计哲学：青年媒体 / 街头服饰品牌美学，大胆而有趣
- 色彩：奶油色（#FFF8E7）背景、黑色（#000000）文字，搭配亮粉色（#FF1493）+ 青色（#00CED1）+ 黄色（#FFD700）色块
- 比例：50% 背景 / 25% 色块 / 25% 内容
- 字体排印：标题占幻灯片面积的 40-50%（将字体本身作为视觉主体），文字块使用粗黑边框，与正文字号比例为 10:1
- 构图：模块化色块形成“受控的混乱”，层叠式不对称布局，使用粗边框
- 视觉语言：像素风 8-bit 图标、抠图摄影、对话气泡、大胆的图形化表面
- 参考："像 Supreme 型录与 HYPEBEAST 文章的结合——把字体排印当作图形艺术"

**第二梯队（推荐，特定场景效果好）：**

**5. 白板草图** — xkcd白板手绘风
- 设计哲学：xkcd 遇上教授的白板——极致简约迫使注意力集中在想法本身
- 色彩：白色（#FFFFFF）背景、黑色（#000000）墨迹，仅使用一种强调色（红色 #FF4444 或蓝色 #4488FF）
- 比例：85% 留白 / 10% 草图 / 5% 强调高亮
- 字体排印：所有文字都呈现手绘/手写质感，基线粗糙不齐，随处使用箭头和批注。关键数字可放大（60pt+）
- 构图：自由式白板布局，手绘箭头连接概念，配合图示和火柴人，非正式且充满活力
- 视觉语言：火柴人、手绘图表和曲线、摇晃线条、批注箭头、圈出的关键词、方程式布局
- 参考："像 xkcd 的《What If?》解释——用简单图画让复杂概念瞬间变得易懂"

**6. 苏联构成主义** — 苏联构成主义
- 设计哲学：革命宣传海报——通过几何图形和有限配色传递力量
- 色彩：革命红（#CC0000）40% + 黑色（#1A1A1A）25% + 奶油白（#F5E6D3）30%
- 字体排印：所有文字旋转 15-30 度，不使用水平线，采用粗体窄体字
- 构图：从左下延伸至右上的对角楔形，几何图形由小到大排列（形成视觉渐强）
- 视觉语言：不使用渐变，仅使用纯色平涂 + 锐利边缘，限制为三种颜色，具有宣传海报般的力量感
- 参考："像 20 世纪 20 年代的 Rodchenko 海报——力量、紧迫感与几何精度"

**7. 温暖叙事** — 温暖叙事风
- 设计哲学：友好的故事讲述，类似 TED 演讲视觉或 Airbnb 路演演示文稿
- 色彩：暖奶油色（#FDF6EC）背景、深炭灰色（#3D3D3D）文字、珊瑚色（#E17055）强调色
- 比例：60% 暖色背景 / 25% 内容 / 15% 插画
- 字体排印：标题粗壮温暖，与正文字号比例为 3:1。使用短句，不使用项目符号
- 构图：插画占幻灯片面积的 40-50%，文字环绕视觉元素，使用圆润形状
- 视觉语言：暖色调扁平矢量插画、以人物为中心的图像、故事化流程
- 参考："像 Mailchimp 或 Notion 的品牌演示文稿——亲切而有人情味"

**更多风格（第二/三梯队）** 详见 `references/proven-styles-gallery.md`，包括：The Oatmeal信息图漫画、敦煌壁画、浮世绘、孔版印刷Risograph、等轴测Isometric、Bauhaus包豪斯、工程蓝图Blueprint、复古广告Vintage Ad、达达拼贴Collage、像素画Pixel Art

**第四类：Professional / Editorial 设计系统（Path A 专用）**

> ⚠️ 以下风格 **强烈建议使用 Path A（HTML→PPTX）**。它们依赖精确排版、数据可视化和网格系统，AI图片生成无法达到所需精度。口腔行业分析案例已验证 Path A + Pentagram编辑风格的出色效果。

**8. Pentagram 编辑设计** — 编辑杂志风（信息建筑派）
- 设计哲学：Pentagram/Michael Bierut — 字体即语言，网格即思想。用极度克制的设计让数据和内容自己说话
- 色彩：奶油白(#FFFDF7) bg, 近黑(#1A1A1A) text, ONE accent color (如橙红#D4480B或品牌色)
- 比例：60% whitespace / 30% content / 10% accent
- 字体排印：粗黑标题(28pt+) + 轻正文(10-13pt), 英文section label作为设计元素 (INSIGHT / PART 03)
- 构图：瑞士网格系统, 2px黑色边框卡片, 精确的水平分隔线, 数据可视化内嵌
- 视觉语言：极简图标, 条形图/饼图/趋势线, callout框, tag标签
- 参考："像 McKinsey 洞察报告与 Monocle 杂志的结合——数据丰富，却又具备编辑设计的优雅"
- **执行路径: Path A only（HTML→PPTX）**
- **实战验证**: 口腔行业分析15页deck（`_temp/口腔行业分析/slides/`）

**9. Fathom 数据叙事** — 数据叙事风（科学期刊派）
- 设计哲学：Fathom Information Design — 每一个像素都必须承载信息。科学严谨+设计优雅
- 色彩：白(#FFFFFF) bg, 深灰(#333) text, 海军蓝(#1A365D) primary + 一个highlight color
- 比例：50% charts/data / 30% text / 20% whitespace
- 字体排印：GT America/Graphik风格的sans-serif, 大数字(60pt+)作为视觉锚点, 精确的脚注/来源标注
- 构图：高信息密度但不拥挤, 注释系统嵌入布局, small multiples图表阵列, 精确的时间线
- 视觉语言：散点图, 热力图, timeline, 带注释的图表, 数据标签精确到小数
- 参考："像 Nature 论文的数据补充材料与 Bloomberg 数据专题的结合"
- **执行路径: Path A only（HTML→PPTX）**

**10. Müller-Brockmann 网格** — 瑞士网格风（纯粹主义派）
- 设计哲学：Josef Müller-Brockmann — 客观性即美。数学精确的网格系统让任何混乱的信息变得有序
- 色彩：白(#FFFFFF) bg, 黑(#000) text, 最多一个强调色
- 比例：70% structured grid / 20% text / 10% accent
- 字体排印：Akzidenz-Grotesk/Helvetica, 严格的8pt基线网格, 绝对左对齐, 字重对比(300 vs 700)
- 构图：8列数学网格, 所有元素对齐到网格线, 绝对不允许装饰元素, 功能主义至上
- 视觉语言：纯几何图形, 黑色线条表格, 精确对齐的列表, 无图标无插画
- 参考："像最初的 Swiss Style 海报——永不过时、理性、零装饰"
- **执行路径: Path A only（HTML→PPTX）**

**11. Build 奢华极简** — 奢侈极简风（当代品牌派）
- 设计哲学：Build Studio — 精致的简单比复杂更难。用大量留白和微妙字重变化传达高端感
- 色彩：纯白(#FFFFFF) bg, 深灰(#2D2D2D) text, 单一accent(品牌色)极少量使用
- 比例：75% whitespace / 15% text / 10% accent
- 字体排印：字重变化极微妙(200-600), 标题巨大(48pt+)但轻, 正文小而精(12pt), 字间距宽松
- 构图：黄金比例构图, 元素极少, 每页只说一件事, 呼吸感优先
- 视觉语言：高端产品图(如果有), 极简图标线条, 大面积纯色块, 圆角卡片
- 参考："像 Apple keynote 与 Celine 型录的结合——自信而克制"
- **执行路径: Path A（HTML→PPTX）**

**12. Takram 思辨设计** — 日式思辨风（东方哲学派）
- 设计哲学：Takram — 技术是思考的媒介。用柔和的科技感和概念原型图传达深度思考
- 色彩：暖灰(#F5F3EF) bg, 深灰(#3D3D3D) text, 鼠尾草绿(#8B9D77) accent
- 比例：55% warm bg / 25% diagrams / 20% text

- 构图：柔和阴影(blur 20px+), 圆角(16px+), 概念图/流程图作为核心视觉, 卡片式布局
- 视觉语言：概念原型图, 柔和渐变, 流程图即艺术, 手绘感图标, 自然色调
- 参考："像 Takram 项目页面——技术令人深思，而不具攻击性"
- **执行路径: Path A（HTML→PPTX，配图可AI辅助生成）**

### 步骤 3-B：完整 AI 幻灯片生成（路径 B）

将每一页幻灯片都生成完整的 AI 图片——布局、文字和视觉元素全部融为一体。

**⚠️ 第一大错误：使用布局细节和视觉限制过度约束提示词。**
约束越多 = 创造力和多样性越低。当提供氛围 + 参考风格 + 内容，而不是具体位置、颜色比例或角色限制时，AI 的生成效果最佳。

#### AI 图片提示词的黄金法则

**短提示词 > 长提示词。** 用 3 句话描述氛围和内容，比用 30 行规定每个视觉细节的效果更好。具体而言：

| 不要这样做（扼杀多样性） | 应该这样做（激发创造力） |
|---|---|
| 指定颜色比例（60%/25%/15%） | 描述氛围（“像周日漫画页一样温暖”） |
| 规定布局位置（“标题居中，图片在右侧”） | 引用一种具体美学（“Peanuts 连环漫画”） |
| 限制角色（“不要是 Snoopy——要原创角色”） | 让 AI 自然解读该风格 |
| 列出必须包含的每一个视觉元素 | 描述希望观众产生的感受 |
| 在每页提示词中重复基础风格 | 只定义一次基础风格，让逐页提示词保持简短 |

#### 基础风格提示词——保持简短

定义一次基础风格，并附加到每一页幻灯片的提示词中。**控制在 5 行以内。** 基础风格负责设定氛围；逐页提示词负责添加内容。

```
[基础风格]:
视觉参考：[用一句话描述具体的艺术/设计美学]
画布：16:9 宽高比，2048x1152 像素，高质量渲染。
色彩系统：[描述色彩的氛围/感受，而不是精确比例]
```

**示例（好——简洁）：**
```
视觉参考：Charles Schulz 的 Peanuts 连环漫画——温暖、富有哲理、迷人。
角色包括圆头小孩、一只惹人喜爱的小猎犬和一只黄色小鸟。
画布：16:9 宽高比，2048x1152 像素，高质量渲染。
色彩系统：温暖的奶油色/报纸色调背景，柔和低饱和的粉彩色，温暖的墨线。
```

**反面模式（差——规定过细）：** 不要在基础风格中包含字体大小、颜色比例、构图百分比、边距规范或视觉权重分配。这些约束会降低多样性，却无法提升质量。

#### 逐页提示词结构

逐页提示词应当**简短且聚焦**。不要重复基础风格细节，也不要过度规定视觉布局。

```
创建一页关于[主题]的[风格]幻灯片。

[基础风格]

设计意图：[用一句话描述希望观众产生的感受]

需要渲染的文字：
- 标题："[精确文字]"
- 正文："[精确文字]"

[可选：用 1-2 句话描述氛围或场景。让 AI 自行决定构图。]
```

#### 示例——好与差

**差（传统 PPT——无聊）：**
```
设计一页专业演示文稿幻灯片。
专业演示文稿幻灯片，16:9 宽高比，2048x1152 像素。
深海军蓝背景、浅灰色文字、金色强调色。
幻灯片类型：内容页。布局：标题位于左上方，下方分为两栏。
标题："看涨期权收益结构"
正文："行权价: 100元, 权利金: 10元"
视觉元素：展示看涨期权收益的折线图
```
→ 结果：任何模板都可能生成的普通 PPT

**好（杂志级——惊艳）：**
```
创建一页幻灯片，让它感觉像 Bloomberg 终端的数据可视化
化身为编辑艺术。

视觉参考：Bloomberg Businessweek 数据专题与电影级灯光的结合。
画布：16:9，2048x1152，清晰渲染。
色彩系统：深黑色（#0A0A0A）背景占 75%，白色文字占 15%，
金色（#BF9A4A）强调色占 10%。金色代表利润——它应该发光。
字体排印：数字“110”以 100pt 渲染，作为主要视觉锚点
（盈亏平衡点就是故事本身）。辅助文字使用 14pt、低调灰色。

设计意图：观众应当立即感受到期权的不对称性——
下行损失有限，上行收益无限。视觉必须让这种感受直击人心，
而不仅仅是传递信息。

需要渲染的文字：
- 核心指标："110"（巨大、金色，代表盈亏平衡价格）
- 标题："盈亏平衡点"（中等大小、白色，位于数字上方）
- 左侧数据："行权价 100" "权利金 10"（小号、灰色、低调）
- 洞察："亏损有底 盈利无限"（强调色，位于底部）

视觉叙事：一条金色曲线从幻灯片左侧出现，
在 -10（最大损失）处保持平坦且呈低调灰色，随后在行权价处突然向上弯曲，
进入盈利区时由灰色转变为耀眼的金色。曲线应当像一道光
冲破黑暗。零点上方的盈利区域泛着温暖金光，
如同日出。图表不要网格线，也不要坐标轴标签
干扰视觉——只保留纯粹而富有戏剧性的曲线，以及巨大的“110”
悬浮在拐点处。
```
→ 结果：讲述故事的编辑式数据可视化

#### 路径 B 提示词关键规则

**提示词质量检查清单（每次生成前都要验证）：**

1. **视觉参考**——提示词是否指明了具体的艺术风格或出版物？（而不只是“专业”或“现代”）
2. **氛围，而非布局**——提示词是否描述了观众应该产生的感受，而不是元素应该放置的位置？
3. **文字内容**——是否清晰、准确地列出了所有需要渲染的文字？
4. **足够简短**——提示词是否简洁？包含详细规格的长提示词会降低多样性。删除任何可由 AI 自主决定的内容。
5. **不做微观管理**——没有十六进制颜色比例、字体大小、构图百分比或角色姿势说明。

**技术规则：**
- **始终指定分辨率**：`2048x1152`（2K、16:9），以获得清晰文字
- **逐字包含所有文字**——AI 必须渲染精确的文字
- **中文优先**：slide上的文字一律用中文，仅保留必要英文术语
- **中文文字技巧**：标题尽量简短（≤8 个字符），以获得最佳渲染效果
- **使用描述性段落**，不要使用关键词列表
- **并行生成**：同时运行 3-5 页幻灯片生成任务以提高速度
- **一致性**：基础风格必须应用于每一页幻灯片。它是一套系统，而不是建议

**生成后的质量检查：**
1. **文字准确性**——验证所有中文/英文文字是否正确渲染
2. **布局**——元素是否按描述放置
3. **风格一致性**——各页幻灯片的颜色和设计语言是否一致
4. 如果某页存在文字错误 → 调整提示词后重新生成（简化或缩短文字）

## 步骤 4：PPTX 组装

### 4-A：html2pptx 工作流（路径 A）

为每页幻灯片创建 HTML 文件，并使用 `html2pptx.js` 转换：

```javascript
const pptxgen = require('pptxgenjs');
const html2pptx = require(process.env.HOME + '/.agents/skills/pptx/scripts/html2pptx.js');

const pptx = new pptxgen();
pptx.layout = 'LAYOUT_16x9';
await html2pptx('slide1.html', pptx);
await html2pptx('slide2.html', pptx);
await pptx.writeFile({ fileName: 'output.pptx' });
```

**HTML 规则**（来自 pptx skill）：
- Body 尺寸：`width: 720pt; height: 405pt`（16:9）
- 所有文字都必须放在 `<p>`、`<h1>`-`<h6>`、`<ul>`、`<ol>` 标签中
- 背景/边框只能应用于 `<div>` 元素
- 不使用 CSS 渐变——使用 Sharp 预渲染为 PNG
- 仅使用网页安全字体（Arial、Helvetica、Georgia 等）
- 图片：`<img src="illustration.png" style="width: Xpt; height: Ypt;">`

**已知问题：** 文件路径中的中文字符可能导致图片加载失败。如有需要，请使用符号链接映射到 ASCII 路径：
```bash
ln -sf "/path/with/中文/" /tmp/ascii-path
```

### 4-B：图片组装（路径 B）

使用 `create_slides.py` 将生成的幻灯片图片组装成 PPTX：

```bash
uv run ~/.claude/skills/image-to-slides/scripts/create_slides.py \
  slide-01-cover.png slide-02-intro.png slide-03-definition.png ... \
  --layout fullscreen \
  --bg-color 000000 \
  -o output.pptx
```

**路径 B 的推荐布局：`fullscreen`**——由于图片已经包含全部布局、文字和视觉元素，因此应让图片填满整张幻灯片。

| 布局 | 使用场景 |
|--------|----------|
| `fullscreen` | AI 生成的全页幻灯片（路径 B 默认） |
| `title_above` | 图片 + 可编辑标题（混合方式） |
| `title_left` | 分栏：文字 + 视觉元素 |
| `center` | 带内边距的居中图片 |
| `grid` | 每页放置多张图片 |
