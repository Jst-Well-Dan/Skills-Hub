# Ponytail 收益

调用时显示此记分板。仅一次：不要更改模式、写入标志
文件或持久化任何内容。

这些数字是已发布的基准测试中位数（5 个日常任务：电子邮件
验证器、防抖、CSV 求和、倒计时器、速率限制器；三个模型：
Haiku、Sonnet、Opus）。它们是实测结果，并非根据当前仓库计算得出。
来源：`benchmarks/` 和 README。

## 诚实边界

这些是基准测试中位数，并非此仓库的数据。绝不要输出针对单个仓库的节省
数值（“你在这里节省了 X 行代码/令牌”）：未构建的版本从未
被写出，因此在实际仓库中不存在可供相减的真实基线。
唯一真实的单仓库数据来自 `/ponytail-debt`（经过计数的台账），
因此此卡片会指向那里，而不是凭空捏造数据。

## 边界

一次性展示。不编辑任何内容，也不更改任何模式。
"停止 ponytail" 或 "正常模式"：恢复原状。
