## 设计构思

**不要创建乏味的幻灯片。** 白色背景上的普通项目符号不会给任何人留下深刻印象。请为每张幻灯片考虑使用此列表中的构思。

### 开始之前

- **选择大胆且由内容决定的配色方案**：配色方案应让人感觉是专门为当前主题设计的。如果将你的配色换到完全不同的演示文稿中仍然“适用”，说明你的选择还不够有针对性。
- **突出主次，而非平均分配**：一种颜色应占据主导地位（60-70% 的视觉权重），搭配 1-2 种辅助色调和一种鲜明的强调色。绝不要让所有颜色拥有相同的视觉权重。
- **深浅对比**：标题和结论幻灯片使用深色背景，内容幻灯片使用浅色背景（“三明治”结构）。也可以全程使用深色背景，营造高级感。
- **坚持一种视觉母题**：选择一个独特元素并反复使用——圆角图片框、彩色圆圈内的图标、粗单侧边框。将其贯穿每张幻灯片。

### 配色方案

选择与主题相符的颜色——不要默认使用通用蓝色。可以从以下配色方案中获取灵感：

| 主题 | 主色 | 辅色 | 强调色 |
|-------|---------|-----------|--------|
| **午夜商务** | `1E2761`（海军蓝） | `CADCFC`（冰蓝） | `FFFFFF`（白色） |
| **森林与苔藓** | `2C5F2D`（森林绿） | `97BC62`（苔藓绿） | `F5F5F5`（奶油色） |
| **珊瑚活力** | `F96167`（珊瑚色） | `F9E795`（金色） | `2F3C7E`（海军蓝） |
| **暖陶土** | `B85042`（陶土色） | `E7E8D1`（沙色） | `A7BEAE`（鼠尾草绿） |
| **海洋渐变** | `065A82`（深蓝） | `1C7293`（蓝绿色） | `21295C`（午夜蓝） |
| **炭灰极简** | `36454F`（炭灰色） | `F2F2F2`（灰白色） | `212121`（黑色） |
| **蓝绿信赖** | `028090`（蓝绿色） | `00A896`（海沫绿） | `02C39A`（薄荷绿） |
| **浆果与奶油** | `6D2E46`（浆果色） | `A26769`（灰玫瑰色） | `ECE2D0`（奶油色） |
| **鼠尾草宁静** | `84B59F`（鼠尾草绿） | `69A297`（桉树绿） | `50808E`（板岩色） |
| **大胆樱桃红** | `990011`（樱桃红） | `FCF6F5`（灰白色） | `2F3C7E`（海军蓝） |

### 每张幻灯片

**每张幻灯片都需要一个视觉元素**——图片、图表、图标或形状。纯文本幻灯片很容易被遗忘。

**布局选项：**
- 双栏布局（左侧文字，右侧插图）
- 图标 + 文本行（图标置于彩色圆圈内，粗体标题，下方为说明）
- 2x2 或 2x3 网格（一侧为图片，另一侧为内容块网格）
- 半出血图片（铺满左侧或右侧），并叠加内容

**数据显示：**
- 大号数据重点展示（60-72pt 的大数字，下方配小标签）
- 对比栏（之前/之后、优点/缺点、并列选项）
- 时间线或流程图（带编号的步骤、箭头）

**视觉润色：**
- 在章节标题旁放置彩色小圆圈内的图标
- 使用斜体强调文字突出关键数据或标语

### 字体排印

**选择有趣的字体搭配**——不要默认使用 Arial。选择一种有个性的标题字体，并搭配一种清晰易读的正文字体。

| 标题字体 | 正文字体 |
|-------------|-----------|
| Georgia | Calibri |
| Arial Black | Arial |
| Calibri | Calibri Light |
| Cambria | Calibri |
| Trebuchet MS | Calibri |
| Impact | Arial |
| Palatino | Garamond |
| Consolas | Calibri |

| 元素 | 大小 |
|---------|------|
| 幻灯片标题 | 36-44pt 粗体 |
| 章节标题 | 20-24pt 粗体 |
| 正文 | 14-16pt |
| 图注 | 10-12pt 柔和色调 |

### 间距

- 最小页边距为 0.5"
- 内容块之间保持 0.3-0.5"
- 留出呼吸空间——不要填满每一寸区域

### 避免（常见错误）

- **不要重复使用相同布局**——在不同幻灯片中变换分栏、卡片和重点标注形式
- **不要将正文居中**——段落和列表应左对齐；仅标题居中
- **不要忽视字号对比**——标题需要达到 36pt+，才能从 14-16pt 的正文中脱颖而出
- **不要默认使用蓝色**——选择能反映具体主题的颜色
- **不要随意混用间距**——选择 0.3" 或 0.5" 的间隔，并保持一致
- **不要只设计一张幻灯片而让其余幻灯片保持朴素**——要么全程贯彻设计，要么始终保持简洁
- **不要创建纯文本幻灯片**——添加图片、图标、图表或其他视觉元素；避免仅使用标题 + 项目符号
- **不要忘记文本框内边距**——将线条或形状与文本边缘对齐时，请在文本框上设置 `margin: 0`，或偏移形状以补偿内边距
- **不要使用低对比度元素**——图标和文本都需要与背景形成强烈对比；避免浅色背景上的浅色文字或深色背景上的深色文字
- **绝不要在标题下使用强调线**——这是 AI 生成幻灯片的典型特征；请改用留白或背景色

## QA（必需）

**假定存在问题。你的工作就是找出它们。**

第一次渲染几乎从来不会完全正确。应把 QA 当作一次缺陷搜寻，而不是确认步骤。如果第一次检查没有发现任何问题，说明你检查得还不够仔细。

### 内容 QA

```bash
python -m markitdown output.pptx
```

检查内容缺失、拼写错误和顺序错误。

**使用模板时，检查是否遗留占位文本：**

```bash
python -m markitdown output.pptx | grep -iE "xxxx|lorem|ipsum|this.*(page|slide).*layout"
```

如果 grep 返回结果，请先修复这些问题，再宣布成功。

### 视觉 QA

**⚠️ 使用子代理**——即使只有 2-3 张幻灯片也要如此。你已经长时间盯着代码，只会看到自己预期看到的内容，而不是实际呈现的内容。子代理能够以全新的视角进行检查。

将幻灯片转换为图片（参见[转换为图片](#转换为图片)），然后使用以下提示词：

```
以视觉方式检查这些幻灯片。假定其中存在问题——找出它们。

检查以下问题：
- 元素重叠（文字穿过形状、线条穿过文字、元素彼此堆叠）
- 文本溢出或在边缘/文本框边界处被截断
- 装饰线按单行文本定位，但标题换成了两行
- 来源引用或页脚与上方内容冲突
- 元素间距过小（< 0.3"）或卡片/章节几乎相互接触
- 间距不均（某处有大片空白，另一处却十分拥挤）
- 距离幻灯片边缘的留白不足（< 0.5"）
- 分栏或相似元素未保持一致对齐
- 低对比度文本（例如奶油色背景上的浅灰色文字）
- 低对比度图标（例如深色背景上的深色图标，且没有使用对比色圆圈）
- 文本框过窄，导致过度换行
- 遗留的占位内容

针对每张幻灯片列出问题或值得关注的区域，即使问题很轻微。

读取并分析以下图片：
1. /path/to/slide-01.jpg（预期：[简要说明]）
2. /path/to/slide-02.jpg（预期：[简要说明]）

报告发现的所有问题，包括轻微问题。
```

### 验证循环

1. 生成幻灯片 → 转换为图片 → 检查
2. **列出发现的问题**（如果没有发现问题，请以更严格的标准再次检查）
3. 修复问题
4. **重新验证受影响的幻灯片**——一次修复通常会产生另一个问题
5. 重复以上步骤，直到完整检查不再发现新问题

**在完成至少一次“修复并验证”循环之前，不要宣布成功。**

## 转换为图片

将演示文稿转换为单独的幻灯片图片，以便进行视觉检查：

```bash
python scripts/office/soffice.py --headless --convert-to pdf output.pptx
pdftoppm -jpeg -r 150 output.pdf slide
```

这会创建 `slide-01.jpg`、`slide-02.jpg` 等文件。

要在修复后重新渲染特定幻灯片：

```bash
pdftoppm -jpeg -r 150 -f N -l N output.pdf slide-fixed
```

## 依赖项

- `pip install "markitdown[pptx]"` - 文本提取
- `pip install Pillow` - 缩略图网格
- `npm install -g pptxgenjs` - 从头创建
- LibreOffice (`soffice`) - PDF 转换（通过 `scripts/office/soffice.py` 为沙盒环境自动配置）
- Poppler (`pdftoppm`) - 将 PDF 转换为图片
