# 主题工厂技能

此技能提供一套精选的专业字体和颜色主题，每个主题都包含精心挑选的调色板和字体组合。选择主题后，即可将其应用于任何制品。

## 用途

使用此技能为演示文稿幻灯片应用一致且专业的样式。每个主题包括：
- 带有十六进制代码的协调调色板
- 用于标题和正文文本的互补字体组合
- 适合不同场景和受众的独特视觉风格

## 使用说明

要为幻灯片或其他制品应用样式：

1. **展示主题陈列文件**：显示 `theme-showcase.pdf` 文件，让用户直观查看所有可用主题。不要对其进行任何修改；只需显示该文件供用户查看。
2. **询问用户的选择**：询问要将哪个主题应用于幻灯片
3. **等待选择**：获取对所选主题的明确确认
4. **应用主题**：选择主题后，将所选主题的颜色和字体应用于幻灯片/制品

## 可用主题

以下 10 个主题可供使用，每个主题均在 `theme-showcase.pdf` 中展示：

1. **海洋深处** - 专业、宁静的海洋主题
2. **日落大道** - 温暖而鲜明的日落色彩
3. **森林树冠** - 自然、沉稳的大地色调
4. **现代极简** - 简洁、现代的灰度风格
5. **黄金时刻** - 浓郁、温暖的秋日调色板
6. **北极霜冻** - 受冬季启发的清冷、明快主题
7. **沙漠玫瑰** - 柔和、精致的灰调色彩
8. **科技创新** - 大胆、现代的科技美学
9. **植物花园** - 清新、自然的花园色彩
10. **午夜星河** - 戏剧化、充满宇宙感的深色调

## 主题详情

每个主题均在 `themes/` 目录中定义，并包含完整的规范，包括：
- 带有十六进制代码的协调调色板
- 用于标题和正文文本的互补字体组合
- 适合不同场景和受众的独特视觉风格

## 应用流程

选择首选主题后：
1. 从 `themes/` 目录读取相应的主题文件
2. 在整套幻灯片中一致地应用指定的颜色和字体
3. 确保适当的对比度和可读性
4. 在所有幻灯片中保持该主题的视觉风格

## 创建自己的主题
当现有主题均不适用于某个制品时，创建自定义主题。根据提供的输入，生成一个与上述主题类似的新主题。为主题取一个风格相似的名称，用于描述字体与颜色组合所表达的意象。根据所提供的任何基本描述选择合适的颜色和字体。生成主题后，展示该主题以供审阅和验证。随后，按照上述方式应用该主题。
