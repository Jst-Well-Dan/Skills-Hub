算法哲学是通过代码表达的计算美学运动。输出 .md 文件（哲学）、.html 文件（交互式查看器）和 .js 文件（生成算法）。

此过程分为两个步骤：
1. 算法哲学创作（.md 文件）
2. 通过创作 p5.js 生成艺术来表达（.html + .js 文件）

首先，执行以下任务：

## 算法哲学创作

首先，创作一种算法哲学（而非静态图像或模板），它将通过以下方式得到诠释：
- 计算过程、涌现行为、数学之美
- 带种子的随机性、噪声场、有机系统
- 粒子、流动、场、力
- 参数化变化与受控混沌

### 关键理解
- 接收到的内容：用户提供的一些需要考虑的微妙输入或指示，但仅将其作为基础；它不应限制创作自由。
- 创作的内容：一种算法哲学／生成美学运动。
- 接下来发生的事情：同一版本接收这套哲学并用代码将其表达出来——创作由 90% 算法生成和 10% 必要参数构成的 p5.js 草图。

可考虑采用以下方式：
- 为一种生成艺术运动撰写宣言
- 下一阶段将编写使其焕发生命的算法

这套哲学必须强调：算法表达。涌现行为。计算之美。带种子的变化。

### 如何生成算法哲学

**为这场运动命名**（1-2 个词）："有机湍流"／"量子和声"／"涌现静谧"

**阐述哲学**（4-6 段——简洁但完整）：

为捕捉算法本质，请表达这套哲学如何通过以下方面呈现：
- 计算过程与数学关系？
- 噪声函数与随机模式？
- 粒子行为与场动力学？
- 时间演化与系统状态？
- 参数化变化与涌现复杂性？

**关键准则：**
- **避免冗余**：每个算法层面只应提及一次。除非能增加新的深度，否则不要重复噪声理论、粒子动力学或数学原理等概念。
- **反复强调匠心**：这套哲学必须多次强调，最终算法应呈现出仿佛经历了无数小时的开发、经过精心打磨，并出自该领域绝对顶尖专家之手的质感。这种表述至关重要——应反复使用诸如“精雕细琢的算法”“深厚计算专业能力的结晶”“不遗余力的优化”“大师级实现”等措辞。
- **保留创作空间**：明确指出算法方向，但要足够简洁，使下一个 Claude 有空间以极高的工艺水准作出诠释性的实现选择。

这套哲学必须引导下一个版本以算法方式表达思想，而不是通过静态图像。美存在于过程之中，而非最终画面。

### 哲学示例

**“有机湍流”**
哲学：受自然法则约束的混沌，从无序中涌现秩序。
算法表达：由多层 Perlin 噪声驱动的流场。数千个粒子跟随向量力运动，其轨迹逐渐累积成有机密度图。多个噪声倍频程创造出湍流区域与平静地带。色彩从速度和密度中涌现——快速粒子明亮燃烧，缓慢粒子淡入阴影。算法持续运行直至达到平衡——这是经过精密调校的平衡，其中每一个参数都由计算美学大师历经无数次迭代精心打磨。

**“量子和声”**
哲学：离散实体呈现出波动般的干涉模式。
算法表达：粒子初始化于网格之上，每个粒子携带一个随正弦波演化的相位值。当粒子彼此靠近时，其相位发生干涉——相长干涉形成明亮节点，相消干涉形成空洞。简单的简谐运动生成复杂的涌现曼陀罗。这是对频率进行不遗余力校准的成果，每个比率都经过精心选择，以产生共振之美。

**“递归低语”**
哲学：跨尺度的自相似，在有限空间中蕴含无限深度。
算法表达：递归细分的分支结构。每条分支都略带随机性，但受黄金比例约束。L 系统或递归细分生成兼具数学感与有机感的树状形态。细微的噪声扰动打破完美对称。线条粗细随每一级递归逐渐减小。每一个分支角度都是深入数学探索的结晶。

**“场动力学”**
哲学：通过不可见之力对物质的作用，使其显现。
算法表达：由数学函数或噪声构建的向量场。粒子诞生于边缘，沿场线流动，在达到平衡或边界时消亡。多个场可以吸引、排斥粒子，或使其旋转。可视化仅展现轨迹——如幽灵般证明不可见之力的存在。这是一场通过力的平衡精心编排的计算之舞。

**“随机结晶”**
哲学：随机过程结晶为有序结构。
算法表达：随机化的圆形填充或 Voronoi 镶嵌。从随机点开始，让它们通过松弛算法演化。单元彼此推离，直至达到平衡。颜色取决于单元大小、邻居数量或距中心的距离。涌现出的有机镶嵌既随机又必然。每个种子都会产生独一无二的晶体之美——这是大师级生成算法的印记。

*以上为精简示例。实际的算法哲学应由 4-6 个内容充实的段落组成。*

### 基本原则
- **算法哲学**：创建一种通过代码表达的计算世界观
- **过程重于产物**：始终强调美从算法的执行中涌现——每次运行都独一无二
- **参数化表达**：思想通过数学关系、力和行为进行传达——而不是静态构图
- **艺术自由**：下一个 Claude 将以算法方式诠释这套哲学——为创造性的实现保留空间
- **纯粹生成艺术**：目标是创造有生命的算法，而不是带有随机性的静态图像
- **专家级工艺**：反复强调最终算法必须呈现出精雕细琢、历经无数次迭代打磨的质感，是计算美学领域绝对顶尖专家深厚专业能力的结晶

**算法哲学应为 4-6 段。** 用富有诗意的计算哲学填充它，将预期愿景融为一体。避免重复相同观点。将这套算法哲学输出为一个 .md 文件。


**参数结构——遵循哲学**：

要建立从算法哲学中自然涌现的参数，请思考：“这个系统的哪些特质可以调整？”

```javascript
let params = {
  seed: 12345,  // 始终包含种子以确保可复现性

  // - 比率（什么比例？）
```

**要设计有效参数，应专注于系统中需要可调的属性，而不是从“模式类型”的角度思考。**

**核心算法——表达哲学**：

**关键要求**：算法哲学应决定要构建什么。

要通过代码表达哲学，请避免思考“我应该使用哪种模式？”，而应思考“如何通过代码表达这套哲学？”

如果哲学关乎**有机涌现**，可考虑使用：
- 随时间积累或生长的元素
- 受自然规则约束的随机过程
- 反馈循环与交互

如果哲学关乎**数学之美**，可考虑使用：
- 几何关系与比率
- 三角函数与和声
- 通过精确计算创造意想不到的模式

如果哲学关乎**受控混沌**，可考虑使用：
- 严格边界内的随机变化
- 分岔与相变
- 从无序中涌现秩序

**算法源自哲学，而不是选项菜单。**

为指导实现，让概念本质塑造富有创意且原创的选择。构建能够表达此次特定请求愿景的作品。

**画布设置**：标准 p5.js 结构：
```javascript
function setup() {
  createCanvas(1200, 1200);
  // 初始化你的系统
}

function draw() {
  // 你的生成算法
  // 可以是静态的（noLoop），也可以是动画

```

### 工艺要求

**关键要求**：为达到大师水准，应创作出仿佛由生成艺术大师历经无数次迭代才形成的算法。仔细调校每个参数。确保每种模式都有目的地涌现。这不是随机噪声——而是通过深厚专业能力打磨出的受控混沌。

- **平衡**：复杂而不产生视觉噪声，有序而不僵化
- **色彩和谐**：使用经过深思熟虑的调色板，而不是随机 RGB 值
- **构图**：即使存在随机性，也要保持视觉层次和流动感
- **性能**：执行流畅；如果是动画，应针对实时运行进行优化
- **可复现性**：相同种子始终产生完全相同的输出

## 交互式产物创建

**提醒：此时应已读取 `templates/viewer.html`（参见步骤 0）。使用该文件作为起点。**

为便于探索生成艺术，请创建一个自包含的单一 HTML 产物。确保此产物可立即在 claude.ai 或任何浏览器中运行——无需设置。将所有内容以内联方式嵌入。

### 关键要求：哪些是固定部分，哪些是可变部分

`templates/viewer.html` 文件是基础。它包含所需的确切结构和样式。

**固定部分（始终完全按照原样包含）：**
- 布局结构（页眉、侧边栏、主画布区域）
- Anthropic 品牌设计（UI 配色、字体、渐变）
- 侧边栏中的种子部分：
  - 种子显示
  - 上一个／下一个按钮
  - 随机按钮
  - 跳转到种子的输入框 + Go 按钮
- 侧边栏中的操作部分：
  - 重新生成按钮
  - 重置按钮

**可变部分（为每件艺术作品进行定制）：**
- 整个 p5.js 算法（setup/draw/类）
- 参数对象（定义艺术作品所需内容）
- 侧边栏中的参数部分：
  - 参数控件的数量
  - 参数名称
  - 滑块的最小值／最大值／步长值
  - 控件类型（滑块、输入框等）
- 颜色部分（可选）：
  - 某些艺术作品需要颜色选择器
  - 某些艺术作品可能使用固定颜色
  - 某些艺术作品可能是单色的（无需颜色控件）
  - 根据艺术作品的需要作出决定

**每件艺术作品都应拥有独特的参数和算法！** 固定部分提供一致的 UX——其他一切都用于表达独特愿景。

### 必需功能

**1. 参数控件**
- 用于数值参数的滑块（粒子数量、噪声尺度、速度等）
- 用于调色板颜色的颜色选择器
- 参数发生变化时实时更新
- 用于恢复默认值的重置按钮

**2. 种子导航**
- 显示当前种子编号
- 用于循环切换种子的“上一个”和“下一个”按钮
- 用于生成随机种子的“随机”按钮
- 用于跳转到特定种子的输入框
- 在用户提出要求时生成 100 个变体（种子 1-100）

**3. 单一产物结构**
```html
<!DOCTYPE html>
<html>
<head>
  <!-- 来自 CDN 的 p5.js——始终可用 -->
  <script src="https://cdnjs.cloudflare.com/ajax/libs/p5.js/1.7.0/p5.min.js"></script>
  <style>
    /* 所有样式均为内联——简洁、极简 */
    /* 画布位于上方，控件位于下方 */
  </style>
</head>
<body>
  <div id="canvas-container"></div>
  <div id="controls">
    <!-- 所有参数控件 -->
  </div>
  <script>
    // 所有 p5.js 代码都内联于此
    // 参数对象、类、函数
    // setup() 和 draw()
    // UI 处理程序
    // 一切均自包含
  </script>
</body>
</html>
```

**关键要求**：这是一个单一产物。不得使用外部文件，不得使用导入（p5.js CDN 除外）。一切都以内联方式包含。

**4. 实现细节——构建侧边栏**

侧边栏结构：

**1. 种子（固定）**——始终完全按照原样包含：
- 种子显示
- 上一个／下一个／随机／跳转按钮

**2. 参数（可变）**——为艺术作品创建控件：
```html
<div class="control-group">
    <label>参数名称</label>
    <input type="range" id="param" min="..." max="..." step="..." value="..." oninput="updateParam('param', this.value)">
    <span class="value-display" id="param-value">...</span>
</div>
```
根据参数数量添加相应数量的 control-group div。

**3. 颜色（可选／可变）**——如果艺术作品需要可调颜色，则包含此部分：
- 如果用户应能控制调色板，则添加颜色选择器
- 如果艺术作品使用固定颜色，则跳过此部分
- 如果艺术作品为单色，则跳过此部分

**4. 操作（固定）**——始终完全按照原样包含：
- 重新生成按钮
- 重置按钮
- 下载 PNG 按钮

**要求**：
- 种子控件必须正常工作（上一个／下一个／随机／跳转／显示）
- 所有参数都必须具有 UI 控件
- 重新生成、重置、下载按钮必须正常工作
- 保留 Anthropic 品牌设计（UI 样式，而不是艺术作品的颜色）

### 使用产物

HTML 产物可立即运行：
1. **在 claude.ai 中**：显示为交互式产物——立即运行
2. **作为文件**：保存后可在任何浏览器中打开——无需服务器
3. **分享**：发送 HTML 文件——它完全自包含

**其他一切都是可变的**：
