# 杜绝废话

消除散文中容易识别的 AI 写作模式。

## 核心规则

1. **删掉填充短语。** 删除清嗓式开场、用于强调的拐杖词以及所有副词。参见 [references/phrases.md](references/phrases.md)。

2. **打破公式化结构。** 避免二元对立、否定式列举、戏剧化断句、设问式铺垫和虚假主体。参见 [references/structures.md](references/structures.md)。

3. **使用主动语态。** 每句话都需要一个正在做事的人类主语。不要使用被动结构。不要让无生命的事物执行人的动作（“投诉变成了解决方案”）。

4. **写具体。** 不要使用含糊的断言（“原因是结构性的”）。明确指出具体事物。不要让偷懒式的极端词（“每个”“总是”“从不”）含糊代劳。

5. **让读者身临其境。** 不要使用置身事外的叙述口吻。用“你”胜过用“人们”。具体细节胜过抽象概念。

6. **改变节奏。** 混合使用长短句。两项胜过三项。用不同方式结束段落。不要使用破折号。

7. **信任读者。** 直接陈述事实。省去弱化语气、辩解和手把手引导。

8. **删掉金句。** 如果一句话听起来适合被摘出来引用，就重写它。

## 快速检查

交付散文前：

- 有副词吗？删掉。
- 有被动语态吗？找出动作执行者，让其成为主语。
- 有无生命的事物在执行人的动作吗（“决定浮现出来”）？明确指出具体的人。
- 句子以疑问词开头吗？重构句子。
- 有“下面来看/这个/那个”之类的清嗓式铺垫吗？直接切入要点。
- 有“不是 X，而是 Y”式对比吗？直接陈述 Y。
- 连续三个句子的长度相近吗？打破其中一个。
- 段落以铿锵有力的短句结尾吗？换一种方式。
- 任何地方用了破折号吗？删除。
- 有含糊的断言吗（“影响十分重大”）？明确指出具体影响。
- 有置身事外的叙述吗（“没人设计过这个”）？让读者进入具体场景。
- 有元话语衔接句吗（“本文其余部分……”）？删除。让文章自然推进。

## 评分

按每个维度以 1-10 分评分：

| 维度 | 问题 |
|-----------|----------|
| 直接性 | 是直接陈述，还是预告式表达？ |
| 节奏 | 富于变化，还是像节拍器一样单调？ |
| 信任 | 是否尊重读者的理解力？ |
| 真实性 | 听起来像人写的吗？ |
| 密度 | 还有可以删掉的内容吗？ |

低于 35/50：修改。
