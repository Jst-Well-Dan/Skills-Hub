# 应用 UX：键盘快捷键与通用范式

## 用户偏好

**默认遵循桌面应用和现代 Web 的惯例。** 用户不应费力寻找关闭方式，也不应只能偶然发现快捷键。除非产品明确选择不采用，否则请实现以下模式。

与 **sync-url-navigation** 技能配合使用，使导航/筛选状态可添加书签。

## 键盘快捷键

### 必备行为

| 按键/组合键 | 预期行为 |
|-------------|-------------------|
| **Esc** | 关闭最上层浮层：模态框、抽屉、弹出框、上下文菜单、行内编辑。如果破坏性保存操作正在进行，则不要关闭——在 `saving` 期间阻止 Esc，或显示清晰的状态。 |
| **⌘/Ctrl+Enter** | 提交主表单，或在聊天/编辑器中发送消息（当焦点位于文本字段中时）。 |
| **Enter** | 提交单行字段；在多行字段中，Enter = 换行，除非已明确说明 Shift+Enter 用于发送。 |
| **⌘/Ctrl+字母** | 用于全局切换操作（例如 **⌘/Ctrl+J** = 打开助手面板）。始终同时支持 `metaKey`（Mac）和 `ctrlKey`（Windows/Linux）。 |

### 实现说明

- 浮层打开时添加**文档级** `keydown` 监听器；组件卸载时移除。
- 处理 Esc 时调用 `event.preventDefault()`，避免嵌套的浏览器 UI 抢占该按键。
- 在图标按钮的 **`title` 工具提示**中显示快捷键（例如 `关闭 (Esc)`）。
- 在应用内的**帮助**部分以 `<kbd>` 样式展示相同的快捷键。
- 避免快捷键冲突：当组合键有明确限定时，检查 `!event.shiftKey` / `!event.altKey`（例如 Ctrl+J 与 Ctrl+Shift+K）。

### 可选但有价值

| 模式 | 使用场景 |
|---------|----------|
| **⌘/Ctrl+K** | 命令面板/快速打开（如果应用具备此功能） |
| **⌘/Ctrl+Shift+K** | 次要全局操作（例如清空聊天/重置上下文）——仅当它与 Ctrl+K 明确区分时使用 |
| **?** | 切换键盘快捷键帮助（未在输入框中输入时） |
| **/** | 聚焦搜索框（未在输入框中时） |

## 模态框和浮层

| 范式 | 要求 |
|----------|-------------|
| **Esc** | 关闭模态框（见上文）。 |
| **点击背景遮罩** | 点击面板外部的暗色区域时关闭（调用与 × 相同的 `close()`）。 |
| **× 控件** | 位于右上角（或统一使用的角落），设置 `type="button"`，并通过 `title` 标签提示 Esc。 |
| **点击事件传播** | 在面板内容上调用 `stopPropagation`，防止内部点击导致关闭。 |
| **焦点** | 打开时将焦点移入模态框；关闭时尽可能将焦点返回触发元素。 |
| **滚动** | 对全屏浮层锁定或限制页面主体滚动；较长表单内部应允许滚动。 |

对**演讲者编辑器**、**时段编辑器**、确认对话框以及任何 `fixed inset-0` 浮层应用相同的关闭三件套（**Esc**、背景遮罩、×）。

## 菜单和临时 UI

- **上下文菜单**：Esc 关闭；点击外部关闭（在 document 上监听 `mousedown`）。
- **悬停卡片/工具提示**：除非它们是模态式的，否则不要捕获 Esc；指针移出时关闭，如果是粘滞式则也可通过 Esc 关闭。
- **行内编辑**（例如网格单元格）：Esc 取消编辑且不保存。

## 表单和异步操作

- **保存**期间禁用主提交按钮；按钮文本显示为 `保存中…`。
- 在表单下方显示**行内错误**，不要只使用 `alert`。
- **必填字段**：提交时验证；聚焦第一个无效字段。
- **清除**会将筛选条件重置为空的默认值；如果使用查询参数路由，还应同步 URL。

## 列表、表格和选择

- **点击行**打开编辑器或展开详细信息（同一表格内保持一致）。
- 存在批量操作时，使用 **Shift+点击**进行多选；显示选中状态视觉效果和批量操作栏。
- **ID 标签**：点击后复制到剪贴板，并短暂显示状态反馈（`已复制`）。
- **空状态**：说明为何没有行（无数据、无匹配结果或筛选条件过窄）。
- 对长表格使用**加载更多**，不要一次渲染数千行。

## 搜索和筛选

- 在适当场景使用 `type="search"`。
- 更改筛选条件时，将分页/数量限制重置到第一页。
- URL 同步可选择防抖；对于管理工具，立即同步 URL 也可以。

## 反馈和安全

- 对导出、保存、复制、撤销操作使用**状态行**或提示消息——不要静默成功。
- 后端支持时，为可逆的日程/数据编辑提供**撤销**功能。
- **破坏性操作**（删除、回滚）：在模态框内确认或使用 `confirm()`；绝不能只依赖图标按钮。
- **按角色控制的 UI**：对查看者隐藏或禁用编辑操作；在帮助文本中说明原因。

## 无障碍基线

- 交互元素应有可见的焦点环。
- 操作应使用按钮；避免使用不具备 `role` 和键盘支持的 `div onClick`。
- 仅包含图标的控件应提供有意义的 `title` / `aria-label`。
- 不要只依赖颜色表达状态（应使用文本标签或胶囊标签）。

## 新 UI 检查清单

- [ ] 背景遮罩 + × 使用相同的关闭处理函数

- [ ] 快捷键已在工具提示和帮助中说明

## 反模式

- 模态框只有 ×，不支持 Esc 或点击背景遮罩关闭
- 快捷键只写在 README 中，未在 UI 中展示
- 只支持 Mac 的 `metaKey`，不支持 `ctrlKey`
- Esc 关闭了模态框，却让嵌套的上下文菜单留在下层
- 保存/导出/复制失败时没有任何提示
