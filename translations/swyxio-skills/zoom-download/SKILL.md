# Zoom 云端录制内容下载

## 概述
下载最近的 Zoom 云端录制内容，选择正确的文件类型，并跳过已上传的内容。确认旧录制内容已上传后，可以选择将其从 Zoom 删除。

## 要下载哪些录制内容
- **“AI in Action Weekly Jam!”** 会议 → 每周演示/展示
- **Paper Club / 嘉宾专场**（例如“[Person] and swyx”）→ 论文研读
- **跳过**时长不足约 10 分钟的录制内容（测试通话、无效开场）
- 与现有 YouTube 内容进行**交叉核对**，避免重复下载

## 选择正确的文件类型
**关键**：Zoom 为每段录制内容提供 6 种以上的文件类型。始终下载：

| 文件类型 | 是否下载？ | 说明 |
|-----------|-----------|-------|
| 共享屏幕（画廊视图） | **是** | 屏幕共享 + 所有摄像头画面 |
| 画廊视图 | 否 | 仅摄像头画面，无屏幕共享 |
| 共享屏幕（演讲者视图） | 否 | 仅显示当前发言者 |
| 演讲者视图 | 否 | 单个发言者的摄像头画面 |
| 仅音频 | 否 | 无视频 |
| 聊天文件 | 否 | 文本聊天记录 |

### 文件名识别
- **正确**：`GMT[date]_Recording_gallery_[resolution].mp4` — `_gallery_` 后缀（不是 `_gvo_`）
- **错误**：`GMT[date]_Recording_gvo_[resolution].mp4` — `_gvo_` = 仅画廊视图 = 无屏幕共享

### 如何下载
1. 前往 `zoom.us/recording`（如有需要，通过 Google SSO 登录）
2. 在每段录制内容的详情页中，找到 **“Shared screen with gallery view”** 行
3. 将鼠标悬停在该行上以显示下载按钮（出现在右侧）
4. 点击下载 — 文件将保存到 ~/Downloads
5. 等待下载完成后，再处理下一段录制内容

## 通过提取帧分析内容
下载后，提取视频帧以了解每个视频包含的内容：

```bash
# 以约 5 分钟为间隔提取 7 帧（覆盖约 1 小时的视频）
for t in 60 300 600 1200 1800 2400 3000; do
  ffmpeg -ss $t -i "video_file.mp4" -vframes 1 -q:v 2 "frame_${t}s.jpg" -y 2>/dev/null
done
```

目视分析提取的帧，以识别：
- **幻灯片标题**和演示内容
- **演示者姓名**（来自画廊视图中的 Zoom 姓名标签）
- 屏幕上可见的**论文标题**、arxiv 链接或参考资料
- **演示名称**及所展示的工具
- 画廊中可见的**参与者姓名**

保存这些笔记 — 它们将提供给 `youtube-publish` 技能，用于拟定标题和描述。

## 从 Zoom 删除旧录制内容
确认视频已成功上传并发布到 YouTube 后：
- 返回 `zoom.us/recording`
- 选择已经上传的录制内容
- 用户必须亲自执行实际删除操作（永久删除属于禁止执行的操作）
- 告知用户哪些录制内容可以安全删除

## 故障排除
- **同一会议有多段录制内容**：Zoom 有时会拆分较长的会议。下载所有分段。
- **没有“Shared screen with gallery view”**：主持人可能未共享屏幕。下载“Gallery view”作为备用方案，并在 YouTube 描述中注明这一点。
- **大文件（>2GB）**：下载可能需要几分钟。在当前下载完成之前，不要开始下一项下载。
