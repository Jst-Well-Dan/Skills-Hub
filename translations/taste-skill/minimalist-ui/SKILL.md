# 协议：高级实用极简主义 UI 架构师

## 1. 协议概述
名称：高级实用极简主义与编辑风格 UI  
描述：一套高级前端工程指令，用于生成高度精致、极致简约的“文档风格”Web 界面，效果类似顶级工作空间平台。本协议严格要求使用高对比度的暖色单色调色板、定制化的字体层级、精心设计的宏观结构留白、便当网格布局，以及搭配经过审慎选择的柔和低饱和粉彩点缀色的超扁平组件架构。它明确拒绝常见的通用 SaaS 设计趋势。

## 2. 绝对负面约束（禁用元素）
AI 必须严格避免以下通用 Web 开发默认做法：
- 不得使用 "Inter"、"Roboto" 或 "Open Sans" 字体。
- 不得使用 "Lucide"、"Feather" 或标准 "Heroicons" 等通用细线图标库。
- 不得使用 Tailwind 默认的厚重投影（例如 `shadow-md`、`shadow-lg`、`shadow-xl`）。阴影必须几乎不可见，或经过深度定制，呈现超扩散、低不透明度（< 0.05）的效果。
- 不得为大型元素或区块使用主色背景（例如，不得使用亮蓝色、绿色或红色的首屏区块）。
- 不得使用渐变、霓虹色或 3D 玻璃拟态（细微的导航栏模糊效果除外）。
- 不得对大型容器、卡片或主要按钮使用 `rounded-full`（胶囊形状）。
- 不得在代码、标记、文本内容、标题或 alt 文本中的任何位置使用表情符号。应替换为适当的图标或简洁的 SVG 图元。
- 不得使用 "John Doe"、"Acme Corp" 或 "Lorem Ipsum" 等通用占位名称。应使用真实且符合语境的内容。
- 不得使用 AI 文案套话："Elevate"、"Seamless"、"Unleash"、"Next-Gen"、"Game-changer"、"Delve"。应使用平实、具体的语言。

## 3. 字体架构
界面必须依靠强烈的字体对比和高级字体选择来营造编辑风格。
- 主要无衬线字体（正文、UI、按钮）：使用简洁、几何化或富有个性的系统原生字体。目标：`font-family: 'SF Pro Display', 'Geist Sans', 'Helvetica Neue', 'Switzer', sans-serif`。
- 编辑风格衬线字体（首屏标题与引文）：目标：`font-family: 'Lyon Text', 'Newsreader', 'Playfair Display', 'Instrument Serif', serif`。应用紧凑的字距（`letter-spacing: -0.02em` 到 `-0.04em`）和紧凑的行高（`1.1`）。
- 等宽字体（代码、按键、元数据）：目标：`font-family: 'Geist Mono', 'SF Mono', 'JetBrains Mono', monospace`。
- 文本颜色：正文文本不得使用绝对黑色（`#000000`）。使用近黑色/炭灰色（`#111111` 或 `#2F3437`），并采用宽松的 `1.6` 行高以提升可读性。次要文本应使用柔和灰色（`#787774`）。

## 4. 调色板（暖色单色调 + 局部粉彩色）
颜色是一种稀缺资源，仅用于表达语义或进行细微点缀。
- 画布/背景：纯白色 `#FFFFFF` 或暖骨白/米白色 `#F7F6F3` / `#FBFBFA`。
- 主要表面（卡片）：`#FFFFFF` 或 `#F9F9F8`。
- 结构边框/分隔线：超浅灰色 `#EAEAEA` 或 `rgba(0,0,0,0.06)`。
- 强调色：仅使用高度去饱和、漂淡的粉彩色，用于标签、行内代码背景或细微的图标背景。
  - 淡红色：`#FDEBEC`（文本：`#9F2F2D`）
  - 淡蓝色：`#E1F3FE`（文本：`#1F6C9F`）
  - 淡绿色：`#EDF3EC`（文本：`#346538`）
  - 淡黄色：`#FBF3DB`（文本：`#956400`）

## 5. 组件规范
- 便当盒功能网格：
  - 使用非对称 CSS Grid 布局。
  - 卡片必须严格使用 `border: 1px solid #EAEAEA`。
  - 圆角必须利落：最大为 `8px` 或 `12px`。
  - 内边距必须宽裕（例如 `24px` 到 `40px`）。
- 主要行动号召（按钮）：
  - 纯色背景 `#111111`，文本 `#FFFFFF`。
  - 轻微圆角（`4px` 到 `6px`）。不使用 box-shadow。
  - 悬停状态应细微变色为 `#333333`，或采用微缩放 `transform: scale(0.98)`。
- 标签与状态徽章：
  - 胶囊形（`border-radius: 9999px`），使用非常小的字号（`text-xs`），大写并采用宽字距（`letter-spacing: 0.05em`）。
  - 背景必须使用已定义的柔和粉彩色。
- 手风琴组件（FAQ）：
  - 移除所有容器框。项目之间仅使用 `border-bottom: 1px solid #EAEAEA` 分隔。
  - 使用简洁、锐利的 `+` 和 `-` 图标表示切换状态。
- 按键微型 UI：
  - 使用 `<kbd>` 标签将快捷键渲染为实体按键：`border: 1px solid #EAEAEA`、`border-radius: 4px`、`background: #F7F6F3`，并使用等宽字体。
- 仿操作系统窗口装饰：
  - 模拟软件界面时，将其包裹在一个极简容器中，顶部使用白色栏，并包含三个浅灰色小圆点（模拟 macOS 窗口控件）。

## 6. 图标与图像指令
- 系统图标：使用 "Phosphor Icons (Bold or Fill weights)" 或 "Radix UI Icons"，营造技术感和略粗的描边美学。所有图标的描边宽度必须统一。
- 插图：在白色背景上使用单色、粗粝的连续线条墨水草图，并加入一个错位的几何形状，以柔和低饱和粉彩色填充。
- 摄影：使用高质量、低饱和且带暖色调的图像。应用细微叠层（`opacity: 0.04` 的暖色颗粒），使照片融入单色调色板。绝不使用饱和度过高的图库照片。没有真实素材时，使用 `https://picsum.photos/seed/{context}/1200/800` 等可靠占位图。
- 首屏与区块背景：区块不应显得空洞扁平。使用不透明度极低的全宽背景图像、柔和的径向光斑（采用暖色调且 `opacity: 0.03` 的 `radial-gradient`），或极简几何线条图案，在不破坏简洁美学的前提下增加层次感。

## 7. 细微动效与微动画
动效应当近乎无形——确实存在，但绝不分散注意力。目标是沉静的精致感，而非视觉奇观。
- 滚动进入：元素进入视口时柔和淡入。使用 `translateY(12px)` + `opacity: 0`，在 `600ms` 内通过 `cubic-bezier(0.16, 1, 0.3, 1)` 过渡至最终状态。使用 `IntersectionObserver`，绝不使用 `window.addEventListener('scroll')`。
- 悬停状态：卡片通过极细微的阴影变化产生抬升效果（`box-shadow` 在 `200ms` 内从 `0 0 0` 过渡到 `0 2px 8px rgba(0,0,0,0.04)`）。按钮在 `:active` 时以 `scale(0.98)` 响应。
- 错落显现：列表和网格项目以级联延迟进入（`animation-delay: calc(var(--index) * 80ms)`）。绝不一次性挂载所有内容。
- 背景环境动效：可选。使用单个移动极其缓慢的径向渐变色块（`animation-duration: 20s+`、`opacity: 0.02-0.04`）在首屏区块背后漂移。必须应用于 `position: fixed; pointer-events: none` 图层。绝不应用于滚动容器。
- 性能：仅通过 `transform` 和 `opacity` 实现动画。不得使用会触发布局计算的属性（`top`、`left`、`width`、`height`）。谨慎使用 `will-change: transform`，且仅用于正在执行动画的元素。

## 8. 执行协议
当任务要求编写前端代码（HTML、React、Tailwind、Vue）或设计布局时：
1. 首先建立宏观留白。区块之间使用大幅垂直内边距（例如 Tailwind 中的 `py-24` 或 `py-32`）。
2. 将主要排版内容的宽度限制为 `max-w-4xl` 或 `max-w-5xl`。
3. 立即应用自定义字体层级和单色颜色变量。
4. 确保每张卡片、每条分隔线和每个边框都严格遵循 `1px solid #EAEAEA` 规则。
5. 为所有主要内容块添加滚动进入动画。
6. 确保区块通过图像、环境渐变或细微纹理呈现视觉层次——不得使用空洞扁平的背景。
7. 提供能够原生体现这种高端、整洁、编辑风格美学的代码，无需手动调整。
