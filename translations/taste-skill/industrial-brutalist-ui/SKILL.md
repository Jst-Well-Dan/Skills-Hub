# SKILL：工业粗野主义与战术遥测 UI

## 1. 技能元信息
**名称：** 工业粗野主义与战术遥测界面工程  
**描述：** 精通构建融合世纪中叶瑞士字体设计、工业制造手册以及复古未来主义航空航天/军用终端界面的 Web 界面。这一领域要求绝对掌握刚性模块化网格、极端的字体尺度对比、纯粹的实用主义配色，以及以程序方式模拟模拟介质退化（半色调、CRT 扫描线、位图抖动）。目标是构建能够传达原始功能性、机械精度和高数据密度的数字环境，并刻意摒弃传统消费级 UI 模式。

## 2. 视觉原型
该设计系统通过融合两种截然不同但高度兼容的视觉范式来运作。**每个项目只能选择其中一种并贯彻到底。不要在同一界面中交替使用或混合两种模式。**

### 2.1 瑞士工业印刷
源自 20 世纪 60 年代的企业视觉识别系统和重型机械蓝图。
*   **特征：** 高对比度浅色模式（新闻纸/米白色基材）。依赖整体感强、厚重的无衬线字体。使用可见分隔线勾勒毫不妥协的结构网格。以激进且不对称的方式运用负空间，并穿插超大、溢出视口的数字或字形。大量使用原色红作为警示色/强调色。

### 2.2 战术遥测与 CRT 终端
源自机密军事数据库、传统大型机以及航空航天平视显示器（HUDs）。
*   **特征：** 仅使用深色模式。高密度表格数据呈现。等宽字体占据绝对主导地位。整合技术性框架元素（ASCII 括号、十字准线）。应用模拟硬件限制效果（荧光体辉光、扫描线、低位深渲染）。

## 3. 字体架构
字体是主要的结构与装饰基础。图像居于次要地位。该系统要求在尺度、字重和间距方面形成极端差异。

### 3.1 宏观字体（结构性标题）
*   **分类：** 新怪诞体 / 粗重无衬线体。
*   **最佳 Web 字体：** Neue Haas Grotesk (Black)、Inter (Extra Bold/Black)、Archivo Black、Roboto Flex (Heavy)、Monument Extended。
*   **实现参数：**
    *   **尺度：** 使用流式字体以巨大尺度呈现（例如 `clamp(4rem, 10vw, 15rem)`）。
    *   **字距（Letter-spacing）：** 极度紧凑，通常为负值（`-0.03em` 至 `-0.06em`），迫使字形形成坚实的建筑块面。
    *   **行距（Line-height）：** 高度压缩（`0.85` 至 `0.95`）。
    *   **大小写：** 仅使用大写，以强化结构冲击力。

### 3.2 微观字体（数据与遥测）
*   **分类：** 等宽字体 / 技术型无衬线体。
*   **最佳 Web 字体：** JetBrains Mono、IBM Plex Mono、Space Mono、VT323、Courier Prime。
*   **实现参数：**
    *   **尺度：** 固定且较小（`10px` 至 `14px` / `0.7rem` 至 `0.875rem`）。
    *   **字距：** 宽松（`0.05em` 至 `0.1em`），以模拟机械打字机间距或终端字符矩阵。
    *   **行距：** 标准至紧凑（`1.2` 至 `1.4`）。
    *   **大小写：** 仅使用大写。用于所有元数据、导航、单元 ID 和坐标。

### 3.3 纹理对比（艺术性扰动）
*   **分类：** 高对比度衬线体。
*   **最佳 Web 字体：** Playfair Display、EB Garamond、Times New Roman。
*   **实现参数：** 使用必须极其克制。必须施加强烈的后期处理（半色调滤镜、1 位抖动），以削弱矢量图形的完美感，并与干净的无衬线字体形成纹理上的并置对比。

## 4. 色彩系统
色彩架构毫不妥协。严禁使用渐变、柔和投影和现代半透明效果。颜色用于模拟物理介质或原始发光显示器。

**关键：每个项目只能选择一种基底配色，并始终如一地使用。绝不能在同一界面中混合浅色与深色基底。**

### 如果选择瑞士工业印刷（浅色）：
*   **背景：** `#F4F4F0` 或 `#EAE8E3`（哑光、未漂白的文档纸张）。
*   **前景：** `#050505` 至 `#111111`（碳黑油墨）。
*   **强调色：** `#E61919` 或 `#FF2A2A`（航空/危险警示红）。这是唯一允许使用的强调色。用于删除线、粗结构分隔线或关键数据高亮。

### 如果选择战术遥测（深色）：
*   **背景：** `#0A0A0A` 或 `#121212`（停用状态的 CRT。避免使用纯 `#000000`）。
*   **前景：** `#EAEAEA`（白色荧光体）。这是主要文本颜色。
*   **强调色：** `#E61919` 或 `#FF2A2A`（航空/危险警示红）。使用相同的红色及相同规则。
*   **终端绿色（`#4AF626`）：** 可选。仅用于一个特定的 UI 元素（例如一个状态指示器或一项数据读数）——绝不能作为通用文本颜色。如果没有明确用途，则完全省略。

## 5. 布局与空间工程
布局必须呈现出经过数学设计的观感。它拒绝传统的 Web 内边距，转而采用可见的分区结构。

*   **蓝图网格：** 严格遵循 CSS Grid 架构。元素不能浮动；必须精确锚定于网格轨道和交点。
*   **可见分区：** 广泛使用实线边框（`1px` 或 `2px solid`）划分不同的信息区域。水平分隔线（`<hr>`）通常横跨整个容器宽度，以分隔各个操作单元。
*   **双模态密度：** 布局在极高的数据密度（紧密聚集的等宽字体元数据）与大片经过精确计算、用于框定宏观字体的负空间之间切换。
*   **几何：** 绝对拒绝使用 `border-radius`。所有角必须严格保持 90 度，以强化机械刚性。

## 6. UI 组件与符号系统
以实用主义的工业图形元素取代标准 Web UI 惯例。

*   **语法装饰：** 使用 ASCII 字符框定数据点。
    *   *框定：* `[ DELIVERY SYSTEMS ]`、`< RE-IND >`
    *   *方向：* `>>>`、`///`、`\\\\`
*   **工业标记：** 突出整合注册商标（`®`）、版权（`©`）和商标（`™`）符号，使其作为结构性几何元素发挥作用，而非作为法律文本。
*   **技术性素材：** 在网格交点整合十字准线（`+`）、重复垂直线（条形码）、粗水平警示条纹和随机字符串数据（例如 `REV 2.6`、`UNIT / D-01`），以模拟正在运行的机械过程。

## 7. 纹理与后期处理效果
为避免设计呈现出纯数字化观感，通过 CSS 和 SVG 滤镜在前端中构建模拟介质退化效果。

*   **半色调与 1 位抖动：** 将连续色调图像或大型衬线字体转换为点阵图案。通过预处理实现，或使用 CSS `mix-blend-mode: multiply` 叠加层并结合 SVG 径向点阵图案实现。
*   **CRT 扫描线：** 对终端界面的背景应用 `repeating-linear-gradient`，以模拟水平电子束扫描（例如 `repeating-linear-gradient(0deg, transparent, transparent 2px, rgba(0,0,0,0.1) 2px, rgba(0,0,0,0.1) 4px)`）。
*   **机械噪点：** 在 DOM 根元素上应用全局、低不透明度的 SVG 静态噪点滤镜，为深色与浅色模式统一引入物理颗粒感。

## 8. Web 工程指令
1.  **网格确定性：** 使用 `display: grid; gap: 1px;`，并为父元素与子元素设置对比鲜明的背景色，无需复杂的边框声明即可生成数学上完美、如刀锋般纤细的分隔线。
2.  **语义刚性：** 使用精确的语义标签（`<data>`、`<samp>`、`<kbd>`、`<output>`、`<dl>`）构建 DOM，以准确体现遥测数据的技术属性。
3.  **字体尺度限制：** 仅对宏观字体使用 CSS `clamp()` 函数，确保巨型文本能够随视口积极缩放，同时在不同视口中保持结构完整性。
