# 照片抽象编辑艺术

基于一张上传照片创建一幅完整成图。保持照片忠实原貌；下方抽象面板仅从照片中观察到的空间、明暗和色彩关系中提炼。

## 工作流程

1. 在内部审视照片。识别三到六项决定性的空间事实：主体关系、尺度、轴线、方向、间隔、重叠、纵深、节奏、光线、色彩角色和留白。
2. 将照片保留为上方或主要部分。仅允许为构图所需的等比例缩放或轻微裁切。绝不可重绘、扩展、替换、修饰、应用滤镜，或以其他方式改变其内容。
3. 在下方将保留的关系重构为稀疏的抽象母题——而非缩略图、描摹、插画、矢量图标或风格迁移。优先呈现关系而非轮廓，并仅保留识别独特主体所需的最少辨识线索。
4. 构成一幅纵向作品，使用无纹理、均匀的象牙色下方面板。根据照片调整照片与面板的比例，而非机械地将图像平分。两个部分直接相接，不使用边框、阴影、拼贴、胶带或样机效果。
5. 使用一种主要标记族，且不超过两种辅助标记族。仅从照片中提取低饱和配色；使用充足留白，避免添加虚构的装饰元素、颜色、符号和对称性。
6. 创作一个基于可见事实、由二至五个单词组成的原创英文标题。仅将其置于抽象面板上，采用克制的编辑式衬线字体。仅在能增添含义时添加简短副标题。
7. 仅返回完成的构图。不要添加评论、分析、标题选项、标签、日期、标志或水印。

## 约束

- 将上传照片视为唯一的内容来源。
- 保持面板背景平整、连续且为中性象牙色；排除渐变、纸张纹理、颗粒、光晕、阴影、暗角、污渍、拼贴痕迹和扫描效果。
- 每一个抽象标记都必须可追溯至源照片中的视觉事实。
- 将人物保留为不规则、连续的短竖向标记或轻微渐窄的色块，绝不可绘制头部、肢体、面部或服装。
- 保留地标建筑时，至多使用一至三个身份线索；省略建筑表面细节。
